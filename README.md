# vincentv2_portfolio

Portfolio of Vincent Vinuya, full stack developer. AI speed, human touch.

- Vite + React + GSAP + Lenis, with a three.js hero (a CC0 marble bust from Poly Haven over Michelangelo's fresco)
- Drag the name card to see any part of the page the way an AI would
- `npm install`, then `npm run dev`; `npm run build` for production (deployed on Vercel, `vercel.json` handles `/blog`)
